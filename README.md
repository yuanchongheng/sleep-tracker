# 睡眠规律记录

一个纯前端、单文件的睡眠记录工具，用来记录入睡时间、起床时间、睡眠时长，并观察作息规律性。

## 功能

- 按“起床日”归档每次睡眠
- 自动推导真实入睡日期和起床日期
- 自动计算睡眠时长
- 统计近 7 天平均睡眠时长
- 统计近 14 天入睡/起床时间波动
- 7 日滚动规律性评分
- 作息趋势、睡眠时长和规律性图表
- CSV 导入/导出，兼容旧版格式
- 数据仅保存在浏览器 localStorage 中

## 使用

直接打开 `index.html` 即可使用，无需后端或构建步骤。

> 注意：浏览器本地数据不会自动同步到 GitHub。需要迁移设备或清理浏览器数据前，请先导出 CSV 备份。
